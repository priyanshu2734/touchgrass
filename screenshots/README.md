# Screenshots

**No screenshots are included.** The environment this project was integrated in had no web browser, so none could be
captured honestly. Do not add mock-ups here and present them as the real app.

To capture your own (PowerShell, with the backend and frontend both running, see the root README):

1. Open http://localhost:5173 in a browser and set the window to about 1280x800 (desktop) or use the browser's device
   toolbar at 390x844 (mobile).
2. Capture these pages and save them in this folder with these names:

| File | Page | What to show |
| --- | --- | --- |
| `01-landing.png` | `/` | Hero section |
| `02-planner-ai.png` | `/plan` | A finished plan with the "AI-generated with ..." badge (Ollama running) |
| `03-planner-fallback.png` | `/plan` | A plan with the "Built-in fallback plan, not AI" badge and notice (stop Ollama first) |
| `04-places.png` | `/explore` | Nearby places list after using "Find places near me" or typing a place |
| `05-map.png` | `/explore` | The Map view with markers |
| `06-quests.png` | `/quests` | "What fits today?" with a few limits selected |
| `07-progress.png` | `/progress` | Progress after completing a quest |

Windows shortcut: `Win + Shift + S`. Then uncomment the screenshot section in the root `README.md`.
